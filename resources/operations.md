# App Store Connect MCP

Commerce build: offline validation plus list_apps, get_app_store_state, export_app_store_state and prepare_app_record are exposed. Discovery is GET-only; export writes only a fresh approved local directory. The shared apply_plan/get_operation_status engine is available, with bounded provisioning, metadata, screenshot and commerce adapters. Submission is not available. Plans require an independent host authorization assertion and write mode; uncertain writes are read back, never replayed. plan_commerce_changes manages an explicitly selected simple base price using an exact catalog point. It reads and compares availability, but generic territory mutation is disabled and returned as manualActionRequired. Credentials are loaded only for remote operations. Eight generated AppStore JSON Schemas are exposed as resources and verified against runtime validators. Screenshot bytes are natively decoded on macOS with Apple Swift/ImageIO. Uncertain uploads retain IDs and never automatically replay.

Configure explicit --allowed-root paths for local data access. --allow-writes and --allow-submission are independent operator gates; neither implies a reviewed operation. No repository .env is loaded. Omission means unmanaged. Never share API keys, signed URLs or review contacts through logs.
