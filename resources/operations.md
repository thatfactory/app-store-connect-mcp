# App Store Connect MCP

Screenshot sync build: offline validation plus list_apps, get_app_store_state, export_app_store_state and prepare_app_record are exposed. Discovery is GET-only; export writes only a fresh approved local directory. The shared apply_plan/get_operation_status engine is available, with a bounded bundle-ID/capability adapter. Submission is not available. Plans require an independent host authorization assertion and write mode; uncertain writes are read back, never replayed. plan_provisioning_changes creates immutable plans for explicitly selected identifiers; inspect_xcode_project performs bounded static inspection. plan_metadata_changes manages only selected locales/domains. Shared version/review/category changes need explicit selection. plan_screenshot_changes manages only selected Mac screenshot sets, with complete order and explicit replacement removals. Commerce and submission planners follow in later phases. Credentials are loaded only for remote operations. Eight generated AppStore JSON Schemas are exposed as resources and verified against runtime validators. Screenshot bytes are natively decoded on macOS with Apple Swift/ImageIO. Uncertain uploads retain IDs and never automatically replay.

Configure explicit --allowed-root paths for local data access. --allow-writes and --allow-submission are independent operator gates; neither implies a reviewed operation. No repository .env is loaded. Omission means unmanaged. Never share API keys, signed URLs or review contacts through logs.
