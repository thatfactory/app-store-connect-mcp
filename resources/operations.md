# App Store Connect MCP

Signing build: offline validation plus read-only inventory and explicit provisioning lifecycle tools are exposed. The shared apply_plan/get_operation_status engine covers bounded provisioning, metadata, screenshot, commerce and signing adapters. Submission is not available. plan_signing_changes permits one sensitive certificate, device or profile action at a time; private keys are forbidden and destructive actions remain separate. download_signing_artifact writes only a new approved mode-0600 path and never returns raw bytes. plan_commerce_changes manages an explicitly selected simple base price and reports availability differences without generic territory writes. Plans require independent host authorization; uncertain writes are read back, never replayed. Eight generated AppStore JSON Schemas are exposed as resources and verified against runtime validators.

Configure explicit --allowed-root paths for local data access. --allow-writes and --allow-submission are independent operator gates; neither implies a reviewed operation. No repository .env is loaded. Omission means unmanaged. Never share API keys, signed URLs or review contacts through logs.
