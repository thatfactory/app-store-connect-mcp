# Phase 12 release-candidate evidence

The `1.0.0` source candidate passes all 193 schema, type, unit, contract, security, integration, and workflow checks plus build and packed-package smoke on Node 24, including a fresh local clone with a clean install. The smoke test creates a tarball, verifies its 98-file allowlist, installs it with production dependencies in a fresh external directory, checks its executable/help/version behavior, negotiates MCP over stdio, enumerates every tool and resource, and runs offline repository validation. Dependency audit reports no known vulnerabilities; production dependency licenses are MIT, ISC, BSD-2-Clause, or BSD-3-Clause.

The cross-cutting suite covers canonical root containment and symlink rejection, duplicate-key and malformed JSON, bounded pagination and response bodies, redacted Apple errors, authorization and submission gates, stale plans, dependency injection attempts, cancellation, transfer-host and range validation, secret-safe journals, unknown write outcomes, and no replay. Submission tests prove ordinary apply rejects submission operations, the independent flag is required, all exact operations must be approved, late input changes stop before writes, compatible drafts are reused, conflicts block, and a lost final response is reconciled once.

Live Headroom evidence remains deliberately scoped. Discovery/export, the four-locale metadata update with unchanged English and a repeated no-op, and free-price/all-territory readback were verified. The supplied-assets gate is blocked because genuine localized screenshots were not provided; no placeholders were uploaded. Certificates, devices, profiles, and App Store review submission were not changed for test coverage. There was no genuine intent to submit the current version, and its `AFTER_APPROVAL` setting means later approval may publish automatically.

This is release-candidate evidence, not publication evidence. Tag `1.0.0`, the GitHub release, npm trusted-publisher setup, and `npm publish` remain owner-controlled actions.
